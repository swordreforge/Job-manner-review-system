# 学生画像

学生画像是系统的核心数据之一，它描述了您的教育背景、技能特长和能力水平，是人岗匹配与报告生成的基础。

## 画像内容

一份完整的学生画像包括：

| 信息类别     | 说明                                             |
| ------------ | ------------------------------------------------ |
| **基本信息** | 学校、专业、学历层次                             |
| **技能清单** | 掌握的专业技能与工具                             |
| **项目经验** | 参与过的项目、实习经历                           |
| **能力评分** | 四维评分：技能水平、知识储备、综合能力、实践经验 |

## 建立方式

### 方式一：上传简历

最快捷的方式，详见 [上传简历](/docs/resume-upload) 文档。

### 方式二：手动填写

1. 进入 **学生画像** 页面
2. 点击 **手动填写** 或编辑已有画像
3. 逐项填写个人信息、教育经历、技能等
4. 保存后系统将生成能力评分

## 画像更新

- 您可以随时修改和更新个人画像
- 重新上传简历会重新生成画像
- 建议定期更新以保持匹配结果的准确性
