# LLM 配置管理

管理员可在此页面统一管理 AI 大模型相关配置，包括供应商、模型列表和各功能的模型分配。

## 三卡片架构

页面分为三个标签页，采用层次化配置模式：

```
LlmProvider（供应商）
  └─ LlmModel（模型）
       └─ LlmModelConfig（功能配置）
```

---

## 供应商（Provider）

供应商代表一个兼容 OpenAI 接口的 API 服务商（如阿里云百炼、OpenAI、DeepSeek 等）。

### 字段说明

| 字段 | 说明 |
|---|---|
| 名称 | 供应商标识名称（仅用于展示） |
| Base URL | API 服务的基础地址（如 `https://dashscope.aliyuncs.com/compatible-mode/v1`） |
| API Key | 调用该供应商接口所需的密钥（保存后脱敏显示） |

### 操作

- **添加供应商** — 点击右上角按钮填写信息
- **编辑** — 点击操作列编辑图标修改 Base URL 或 API Key
- **删除** — 删除供应商时，所有关联的模型配置将一并删除

---

## 模型（Model）

模型挂载在供应商下，代表该供应商提供的具体 LLM 模型。

### 字段说明

| 字段 | 说明 |
|---|---|
| 模型 ID | 实际调用的模型名称（如 `qwen-plus`、`gpt-4o`） |
| 显示名称 | 在界面上展示的友好名称 |
| 所属供应商 | 关联的 API 供应商 |
| 输入价格 | 每 1M token 的输入费用（仅供成本参考） |
| 输出价格 | 每 1M token 的输出费用（仅供成本参考） |

---

## 功能配置（Model Config）

功能配置将系统中的各类 AI 功能映射到具体模型，并允许自定义推理参数。

### 功能键（Function Key）说明

| 功能键 | 对应功能 |
|---|---|
| `resume_parse` | 简历解析与能力评分 |
| `student_profile` | 手动画像生成 |
| `match_analyze` | 人岗匹配分析 |
| `report_generate` | 职业规划报告生成 |
| `report_polish` | 报告 AI 润色 |
| `data_clean` | 岗位数据清洗 |
| `profile_generate` | 岗位画像生成 |
| `graph_build` | 职业图谱构建 |
| `chat` | AI 对话助手 |
| `chat_title` | 对话标题自动生成 |

### 字段说明

| 字段 | 说明 |
|---|---|
| 功能键 | 上表中的功能标识 |
| 关联模型 | 选择执行此功能时调用的模型 |
| Temperature | 模型输出的随机性（0–2，推荐 0.7） |

> ⚠️ 功能配置变更后立即生效，会影响后续所有该类型任务的执行。
