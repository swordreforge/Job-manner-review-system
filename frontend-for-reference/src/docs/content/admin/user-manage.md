# 用户管理

管理员可以在用户管理页面查看和管理系统中所有注册用户。

## 功能概览

- 📋 **用户列表** — 查看所有用户的基本信息
- 🔍 **搜索筛选** — 按用户名、角色等条件筛选
- 🔒 **角色变更** — 调整用户角色（普通用户 / 管理员 / 学校管理员）
- 🚫 **禁用账号** — 暂停某用户的登录权限

## 操作指南

### 查看用户列表

进入 **管理功能 → 用户管理**，默认展示所有已注册用户。

### 修改用户角色

1. 在用户列表中找到目标用户
2. 点击操作栏中的角色切换按钮
3. 确认变更

## 角色说明

| 角色 | 权限范围 |
|---|---|
| **STUDENT**（默认） | 使用全部学生功能，可绑定学校 |
| **ADMIN** | 访问所有管理功能，管理用户、任务、LLM 配置等 |
| **SCHOOL** | 学校管理员，可查看本校学生数据、批量创建学生账号 |

> ⚠️ 请谨慎授予管理员权限，管理员可以访问所有管理功能。SCHOOL 角色账号建议通过管理员创建并直接指定，而非升级现有学生账号。
