# 对话记录管理

管理员可在此页面查看系统中所有用户的 AI 对话记录，用于运营监控和问题排查。

## 功能说明

- 分页浏览所有用户的对话会话列表
- 按 **用户名** 搜索筛选特定用户的对话
- 点击查看单条对话的完整消息内容

## 操作步骤

1. 进入 **管理功能 → 对话记录**
2. 在搜索框输入用户名，点击 **搜索** 筛选（留空则显示全部）
3. 点击列表中的 **查看** 按钮，在弹窗中查看完整对话内容

## 列表字段说明

| 字段 | 说明 |
|---|---|
| 标题 | AI 自动生成的对话主题标题 |
| 用户名 | 发起对话的用户 |
| 创建时间 | 对话首次创建的时间 |
| 最后更新 | 最近一次消息的时间 |

## 注意事项

- 对话记录仅供只读查阅，管理员不可修改用户的对话内容
- 当前版本不支持删除用户对话（用户可在对话页面自行删除）
