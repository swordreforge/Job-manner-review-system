# 岗位数据上传

管理员可以通过**文件上传**或 **Open API** 两种方式导入岗位数据，系统将自动触发数据清洗、画像生成和图谱构建流水线。

---

## 方式一：文件上传

### 支持格式

支持以下三种格式：

| 格式 | 扩展名 |
|------|--------|
| Excel 97-2003 | `.xls` |
| Excel 2007+ | `.xlsx` |
| CSV（UTF-8） | `.csv` |

### 上传步骤

1. 进入 **管理功能 → 上传岗位数据**
2. 点击 **选择数据文件** 或拖拽文件到上传区域
3. 点击 **上传并导入** 按钮
4. 上传完成后，页面显示导入统计（总行数 / 成功 / 跳过）
5. 如有新增数据，系统自动触发数据管道，点击 **查看任务队列** 监控进度

### 列名规范

系统同时支持**中文列名**和**英文列名**，可混用，大小写不敏感（英文列名）。

| 字段 | 中文列名（任选一） | 英文列名 |
|------|-------------------|----------|
| 岗位名称 ⭐ | 岗位名称、职位名称 | `job_name` |
| 公司名称 | 公司名称、公司 | `company_name` |
| 工作地址 | 工作地点、工作地址、地址 | `work_address` |
| 薪资范围 | 薪资范围、薪资 | `salary_range` |
| 所属行业 | 行业、所属行业 | `industry` |
| 公司规模 | 公司规模、企业规模 | `company_size` |
| 公司类型 | 公司类型、企业类型、融资阶段 | `company_type` |
| 岗位编码 | 岗位编码、职位编码 | `job_code` |
| 岗位描述 | 岗位描述、岗位详情、职位描述、工作描述、职位详情 | `job_description` |
| 公司简介 | 公司介绍、公司简介、企业介绍、公司详情、企业详情 | `company_intro` |
| 发布日期 | 更新日期、发布日期、更新时间 | `update_date` |
| 来源链接 | 岗位来源地址、来源链接、来源地址 | `source_url` |

> ⭐ **岗位名称**（`job_name`）为唯一必填字段，缺失时该行将被跳过。

## 方式二：Open API 接口

适用于外部系统、数据采集脚本等场景，通过 **API Key** 鉴权调用。

### 前置条件

管理员需先在 **管理功能 → API Key 管理** 中创建一个有效的 API Key。

### 请求说明

```
POST /api/open/jobs
Authorization: X-API-Key: <your-api-key>
Content-Type: application/json
```

请求体示例：

```json
{
  "jobs": [
    {
      "jobName": "前端工程师",
      "companyName": "示例科技有限公司",
      "workAddress": "北京市朝阳区",
      "salaryRange": "15k-25k",
      "industry": "互联网",
      "companySize": "1000-5000人",
      "companyType": "上市公司",
      "jobCode": "FE-001",
      "jobDescription": "负责 Web 前端开发...",
      "companyIntro": "公司简介...",
      "updateDate": "2025-01-01",
      "sourceUrl": "https://example.com/job/1"
    }
  ]
}
```

响应示例：

```json
{
  "code": 200,
  "data": {
    "totalRows": 1,
    "importedCount": 1,
    "skippedCount": 0
  }
}
```

---

## 去重规则

系统以 **岗位名称 + 公司名称**（忽略大小写）的组合作为去重键。重复数据不会再次入库，但不会报错，会在跳过详情中列出（最多展示前 20 条）。

---

## 自动化流水线

有新增数据时，系统自动触发三阶段级联数据管道：

1. **DATA_CLEAN** — 清洗原始数据，过滤非计算机行业岗位，标准化字段格式
2. **PROFILE_GENERATE** — 按职位类别聚合，通过 LLM 生成岗位画像，写入 ChromaDB 向量库
3. **GRAPH_BUILD** — 基于岗位画像构建职业晋升与转岗图谱

整个流水线为级联执行，每步完成后自动触发下一步。进度可在 **任务队列** 页面实时查看。

> 若全部数据均为重复（无新增），则不触发管道。
