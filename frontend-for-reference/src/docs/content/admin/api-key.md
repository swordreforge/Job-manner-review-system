# API Key 管理

管理员可在此页面创建和管理用于 Open API 鉴权的 API Key，供外部系统调用岗位数据导入接口。

## 功能说明

- **查看密钥列表** — 展示已创建的所有 API Key（密钥值脱敏）
- **创建密钥** — 生成新密钥并配置访问策略
- **撤销密钥** — 立即使某个密钥失效

## 创建 API Key

1. 进入 **管理功能 → API Key 管理**
2. 点击 **创建 API Key**
3. 填写以下信息：

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 名称 | **必填** | 密钥用途描述，仅供标识 |
| 过期时间 | 选填 | 留空则永不过期 |
| 速率限制 | 选填 | 每分钟最大请求数，默认 60 |
| IP 白名单 | 选填 | 逗号分隔的允许 IP 列表，留空则不限制 |

4. 点击 **创建**，系统将展示完整密钥值

> ⚠️ **重要**：密钥完整值**仅在创建时展示一次**，请立即复制保存。之后只能看到脱敏后的前缀。

## 使用 API Key

在请求头中携带密钥：

```
X-API-Key: <your-api-key>
```

目前支持的 Open API 接口：

| 接口 | 说明 |
|---|---|
| `POST /api/open/jobs` | 批量导入岗位数据 |

详细接口格式请参阅 [岗位数据上传](/docs/admin/job-upload) 文档。

## 安全建议

- 为每个使用方创建独立的 API Key，方便独立撤销
- 生产环境建议配置 **IP 白名单**，限制调用来源
- 定期检查密钥的使用量，发现异常及时撤销
