# LLM 用量统计

管理员可在此页面查看系统 AI 功能的 Token 消耗情况，支持按日期范围筛选。

## 功能概览

- **总体统计** — 指定时间段内的 Token 消耗汇总
- **每日趋势** — 折线图展示每日消耗变化
- **分模型统计** — 各模型的 Token 消耗占比
- **分任务类型统计** — 各功能的 Token 消耗分布
- **调用记录** — 分页查看每次 LLM 调用的详细日志

## 统计指标

| 指标 | 说明 |
|---|---|
| 输入 Token | 发送给模型的提示词 Token 数量 |
| 输出 Token | 模型生成的响应 Token 数量 |
| 总 Token | 输入 + 输出的合计量 |
| 调用次数 | LLM 接口的调用总次数 |
| 预估费用 | 基于模型定价估算的费用（仅参考） |

## 使用说明

1. 进入 **管理功能 → LLM 用量统计**
2. 在页面顶部选择 **开始日期** 和 **结束日期**（默认最近 30 天）
3. 点击 **查询** 刷新数据
4. 切换底部标签页查看按模型或按任务类型的细分统计

> 预估费用基于 LLM 配置中填写的模型定价计算，如未填写价格则显示为 0。
