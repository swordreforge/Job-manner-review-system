# 岗位图谱

岗位图谱以可视化图形展示不同岗位之间的关联关系，帮助您理解职业晋升路径和转型方向。

## 功能说明

进入 **岗位图谱** 页面，您将看到一个交互式的关系图：

- **节点** — 代表一个岗位类别
- **连线** — 代表岗位之间的晋升或转型关系
- **箭头方向** — 表示发展方向（从低阶到高阶，或横向转型）

## 交互操作

- 🖱️ **拖拽** — 移动节点位置
- 🔍 **缩放** — 鼠标滚轮调整视图大小
- 👆 **点击节点** — 查看该岗位的详细信息
- 📐 **自动布局** — 系统会自动计算最佳展示布局

## 数据来源

图谱基于 AI 对岗位画像的深度分析自动构建，包含：

- **技能重叠度** — 两个岗位所需技能的相似程度
- **知识关联性** — 知识体系的传承与递进关系
- **行业实践** — 现实中常见的职业发展路径

> 图谱数据会随着岗位画像的更新而自动刷新。
