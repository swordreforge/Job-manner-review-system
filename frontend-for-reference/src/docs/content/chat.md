# AI 职业规划助手

AI 职业规划助手是基于大模型的对话式咨询功能，可根据您的学生画像提供个性化的职业建议。

## 功能入口

点击侧边栏 **AI 助手** 进入对话页面。

## 快速提问

页面提供以下快捷问题，点击即可直接发起咨询：

- **我适合哪些职业方向？** — 综合画像推荐匹配的岗位类型
- **如何提升竞争力？** — 给出具体的技能提升建议
- **我的技能有哪些不足？** — 针对目标岗位分析技能差距

## 对话操作

| 操作 | 说明 |
|---|---|
| 输入消息 + **发送** | 发起新一轮对话 |
| `Ctrl + Enter` | 快捷发送消息 |
| **新建对话** | 开始一次全新的对话，不影响历史记录 |
| **历史对话** | 在左侧列表切换或继续已有对话 |
| **删除对话** | 鼠标悬停对话条目，点击删除图标 |

## 对话持久化

每次对话均会自动保存，会话标题由 AI 根据内容自动生成。您可以随时回到历史对话查看之前的咨询记录。

## 前置建议

建立完整的 **学生画像**（通过上传简历或手动填写）后，AI 助手可以根据您的具体情况给出更精准的职业建议。

> 若尚未建立画像，AI 助手仍可回答通用的职业规划问题，但无法结合您的个人情况进行针对性分析。
