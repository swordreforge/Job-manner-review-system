# 人岗匹配

人岗匹配是本系统的核心功能，通过 AI 从四个维度分析您与目标岗位的契合度。

## 前置条件

发起匹配前，请确保：

- ✅ 已建立 **学生画像**（通过上传简历或手动填写）
- ✅ 系统中已有 **岗位画像** 数据

## 匹配流程

1. 进入 **人岗匹配** 页面
2. 选择您感兴趣的 **岗位类别**
3. 点击 **开始匹配**
4. 等待 AI 分析完成（通常 10-30 秒）
5. 查看匹配结果

## 四维匹配模型

| 维度           | 说明                                 | 权重 |
| -------------- | ------------------------------------ | ---- |
| **技能匹配度** | 您掌握的技能与岗位要求的重合度       | 30%  |
| **知识契合度** | 您的知识储备与岗位知识要求的匹配情况 | 25%  |
| **能力适配度** | 综合能力指标与岗位能力模型的吻合程度 | 25%  |
| **综合评估**   | 整体匹配度的综合判断与发展潜力评估   | 20%  |

## 匹配结果

匹配完成后，您将看到：

- **综合匹配分数** — 百分制总分
- **各维度详细分析** — 每个维度的得分和具体说明
- **优势与不足** — AI 识别出的匹配优势点和待提升领域
- **发展建议** — 针对性的学习和提升建议

## 历史记录

所有匹配结果会自动保存，您可以在匹配页面查看历史匹配记录。
