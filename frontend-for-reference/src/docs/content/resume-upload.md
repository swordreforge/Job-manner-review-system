# 上传简历

上传简历是建立个人画像最快捷的方式，AI 将自动完成简历解析与能力评分。

## 操作步骤

1. 进入 **学生画像** 页面
2. 点击 **上传简历** 按钮
3. 选择您的简历文件（支持 PDF / DOCX 格式）
4. 等待 AI 解析完成

## 解析过程

系统收到简历后会自动执行以下流程：

1. **文件解析** — 提取简历中的文本内容
2. **AI 分析** — 大模型识别教育经历、技能、项目经验等结构化信息
3. **能力评分** — 基于提取结果自动生成四维能力评分
4. **画像生成** — 创建完整的学生能力画像

整个过程通常在 **10-20 秒** 内完成。

## 注意事项

- 建议使用排版清晰的简历，避免大量图片和复杂表格
- 简历内容越完整，AI 分析结果越准确
- 如果解析结果不够准确，您可以在学生画像页面手动修正
- 每次上传新简历会覆盖之前的画像数据

## 文件大小限制

单个简历文件不超过 **10 MB**。
