# 学生管理

学校管理员可在学生管理页面查看本校所有学生的基本信息与 AI 分析数据。

## 学生列表

### 查看学生列表

进入 **学生管理** 页面，以分页表格形式展示本校所有学生，每页默认 20 条。

### 搜索学生

在页面顶部搜索框输入用户名或专业关键词，实时过滤匹配的学生记录。

### 列表字段说明

| 字段 | 说明 |
|---|---|
| 用户名 | 学生登录账号名 |
| 专业 | 从学生画像中提取，未建立画像则为空 |
| 画像完整度 | AI 评估的画像信息完整程度（0–100） |
| 竞争力评分 | AI 评估的综合竞争力（0–100） |
| 注册时间 | 账号创建时间 |

> 画像相关字段（专业、完整度、竞争力）仅在学生已完成简历解析或手动填写画像后才有数据。

## 学生详情

点击列表中任一学生，进入 **学生详情** 页面，可查看：

### 基本信息

- 用户名与账号创建时间

### 学生画像

AI 从简历或手动填写中提取的学生综合画像，包含：

- 教育背景（学校、专业、学历）
- 技能列表
- 工作/实习经历
- 竞争力评分与画像完整度

若学生尚未建立画像，此模块显示为空。

### 人岗匹配记录

列出该学生最近 10 次人岗匹配分析的摘要，包括：

- 目标岗位画像 ID
- 综合匹配得分
- 分析时间

### 职业规划报告

列出该学生所有生成的职业规划报告，包括：

- 报告标题
- 状态（草稿 / 生成中）
- 版本号与最后更新时间

### 对话记录

查看该学生与 AI 职业规划助手的历史对话，详见 [查看学生对话记录](/docs/school/student-chats)。

## 注意事项

- 学校管理员只能查看**本校绑定学生**的数据，无法跨校访问
- 数据为**只读**，管理员不可修改学生的任何内容
- 若学生解除了学校绑定，该学生将不再出现在本校列表中
