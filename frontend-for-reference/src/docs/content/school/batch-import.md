# 批量导入学生账号

学校管理员可通过上传 CSV 或 Excel 文件，一次性为本校学生批量创建账号。

## 支持的文件格式

| 格式 | 扩展名 |
|---|---|
| CSV（推荐） | `.csv` |
| Excel 97-2003 | `.xls` |
| Excel 2007+ | `.xlsx` |

## 文件格式规范

### 列结构

| 列 | 字段名 | 是否必填 | 说明 |
|---|---|---|---|
| A 列 | `username` | **必填** | 学生登录用户名，全系统唯一 |
| B 列 | `password` | 选填 | 初始密码；留空则系统自动生成 8 位随机密码 |

### 格式要求

- 第一行为**表头**（`username,password`），从第二行起为数据
- 用户名不可包含空格，建议使用学号或姓名拼音
- 密码留空时，系统生成的随机密码会在导入结果中返回，**请务必保存**

### CSV 示例

```
username,password
zhangsan,MyPass123
lisi,（留空则自动生成密码）
wangwu,
```

> 下载模板：在批量导入页面点击 **下载模板** 按钮，获取标准 CSV 文件。

## 操作步骤

1. 进入 **批量导入** 页面
2. 点击 **下载模板**，按模板填写学生数据
3. 点击 **选择文件** 上传填写好的文件
4. 点击 **开始导入**，等待系统处理
5. 查看导入结果报告

## 导入结果说明

导入完成后，页面展示结果摘要：

| 字段 | 说明 |
|---|---|
| 总行数 | 文件中的数据行数（不含表头） |
| 成功创建 | 实际创建的账号数量 |
| 跳过 | 用户名已存在或为空的行数 |
| 自动生成密码 | 系统为未填写密码的账号生成的密码列表 |

> ⚠️ **重要**：自动生成的密码仅在本次导入结果中显示一次，请立即记录并安全分发给对应学生。

## 常见问题

### 用户名已存在会怎样？

该行会被**跳过**，不会覆盖现有账号，导入结果中计入"跳过"数量。

### 导入后学生需要做什么？

学生用导入的账号登录系统后，建议：
1. 前往 **个人中心** 修改初始密码
2. 在 **个人中心 → 绑定学校** 输入学校邀请码完成绑定（若批量导入账号已自动关联学校，此步可跳过）

> 💡 通过批量导入创建的学生账号已**自动绑定**到本校，无需再手动输入邀请码。

### 文件解析失败怎么办？

请检查：
- 文件格式是否为 CSV / XLS / XLSX
- CSV 文件编码是否为 **UTF-8**（避免中文乱码）
- 是否有合并单元格（Excel 不支持合并单元格导入）
