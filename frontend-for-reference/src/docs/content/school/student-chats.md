# 查看学生对话记录

学校管理员可在学生详情页查看该学生与 AI 职业规划助手的历史对话记录。

## 访问入口

1. 进入 **学生管理** 列表
2. 点击任一学生，进入 **学生详情** 页面
3. 点击顶部标签页 **对话记录**

## 功能说明

- 左侧展示该学生的所有对话会话列表（按最后更新时间降序排列）
- 点击列表中的任一会话，右侧显示该会话的完整消息内容
- 支持查看 AI 回复的完整 Markdown 格式内容

## 字段说明

| 字段 | 说明 |
|---|---|
| 标题 | AI 自动生成的对话主题标题 |
| 创建时间 | 对话首次创建的时间 |
| 最后更新 | 最近一次消息的时间 |

## 权限与数据保护

- 学校管理员只能查看**本校绑定学生**的对话记录
- 对话内容为**只读**，管理员无法修改或删除
- 若学生未发起过任何对话，列表显示为空
