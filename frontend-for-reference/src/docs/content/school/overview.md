# 学校管理员控制台

> 学校管理员账号由系统管理员创建，拥有查看本校学生数据和管理学生账号的专属权限。

## 功能概览

| 功能 | 说明 |
|---|---|
| 🏫 **学校信息** | 查看本校基本信息与邀请码 |
| 👥 **学生列表** | 分页浏览、搜索本校所有学生 |
| 📋 **学生详情** | 查看单个学生的画像、匹配记录与报告 |
| 📥 **批量导入** | 通过 CSV / Excel 文件批量创建学生账号 |

## 快速开始

### 1. 登录系统

使用管理员为您创建的学校管理员账号登录。登录成功后，系统自动跳转至 **学校控制台**。

### 2. 查看学校信息

控制台首页展示本校基本信息，包括：
- 学校名称与描述
- **邀请码** — 学生使用此邀请码在"个人中心"绑定所在学校

### 3. 管理学生

- 前往 **学生管理** 页面，浏览本校已注册学生
- 点击任一学生进入 **学生详情**，查看其 AI 生成的职业画像、人岗匹配记录和规划报告

### 4. 批量导入学生账号

如需为学生批量创建账号，前往 **批量导入** 页面，按模板上传 CSV 或 Excel 文件即可。

## 权限说明

学校管理员账号有以下访问限制：

- ✅ 可查看本校学生的所有数据
- ✅ 可批量创建本校学生账号
- ❌ 无法查看其他学校的学生数据
- ❌ 无法修改学生的画像或报告内容
- ❌ 无法访问学生功能模块（岗位画像、人岗匹配等）

## 邀请码机制

邀请码是学生与学校关联的凭证：

1. 学校管理员在控制台首页获取邀请码（格式：8 位大写字母+数字）
2. 学生在 **个人中心 → 绑定学校** 处输入邀请码完成关联
3. 绑定成功后，学生数据即可在本学校管理员控制台中可见

> 💡 如需更换邀请码，请联系系统管理员在后台重新生成。旧邀请码将立即失效。
