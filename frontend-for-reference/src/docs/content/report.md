# 报告管理

职业规划报告是人岗匹配的延伸产物，由 AI 为您生成个性化的职业发展指导报告。

## 生成报告

1. 完成一次 **人岗匹配** 后，在匹配结果页点击 **生成报告**
2. 或在 **报告管理** 页面点击 **新建报告**
3. 等待 AI 生成（通常 30-60 秒）
4. 生成完成后报告进入 **草稿** 状态

## 报告内容

AI 生成的报告通常包含以下章节：

- **个人画像总结** — 您的能力概览
- **目标岗位分析** — 目标岗位的要求与发展前景
- **匹配分析详情** — 四维匹配的详细解读
- **SWOT 分析** — 优势、劣势、机会、威胁
- **发展路径规划** — 短期与中长期的行动计划
- **学习建议** — 具体的技能提升路径

## 编辑与润色

- 报告支持在线 **富文本编辑**
- 使用 **AI 润色** 功能可优化文笔和结构
- 每次润色会自动增加版本号

## 导出

报告支持导出为 **PDF** 格式，方便打印和分享。
