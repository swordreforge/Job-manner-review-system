## 前言

### 1）项目背景
- 当前招聘与就业服务正从“经验驱动”转向“数据驱动+智能决策”。
- 院校、企业、求职者三方在岗位理解、能力评估、匹配决策上存在信息断层。
- 传统流程工具难以支撑“可解释、可量化、可复盘”的匹配决策。

### 2）项目定位
- 平台定位为“人岗匹配决策基础设施”，核心链路为：
  - 岗位画像 → 人才画像 → 匹配引擎 → 决策报告 → 行动闭环
- 一句话定位：
  - 用可解释的 AI 人岗匹配引擎，帮助机构更高效、更精准地完成“招对人、育对人、用对人”。

### 3）本方案目的
- 明确项目建设方向、核心能力边界与落地路径。
- 为后续详细设计、开发实施、市场推进提供统一纲领。

### 4）本节后续可展开讲解
- 行业趋势数据与政策背景（就业、职教数字化、AI招聘）
- 现有痛点案例（企业端/院校端/候选人端）
- 项目发起原因与阶段目标

## 创意描述

### 1）创意核心
- 将分散的招聘与就业环节，整合为一个“可评估、可追踪、可优化”的统一系统。
- 不只给匹配分数，还输出能力差距、优先提升项与行动建议。

### 2）创新点来源
- 业务对象创新：岗位画像与人才画像统一模型。
- 决策机制创新：匹配引擎提供多维评分+解释依据。
- 结果闭环创新：从推荐到复评形成持续改进闭环。

### 3）与传统方案差异
- 相比 ATS：加强画像与可解释匹配能力。
- 相比单点评测：补齐招聘协同与经营闭环。
- 相比通用大模型：强调业务结构化、流程化与可追溯。

### 4）本节后续可展开讲解
- 创意形成过程（问题→假设→验证）
- 差异化价值证明方式（效率、质量、成本三维）
- 典型使用场景故事线（校企合作、批量招聘）

## 功能简介

### 1）核心功能模块
- 用户与角色权限管理
- 岗位管理与岗位画像生成
- 候选人管理与人才画像生成（含简历解析）
- 智能匹配评分与差距分析
- 报告生成与导出

### 2）用户流程（主链路）
1. 采集建模：录入岗位/简历，生成双画像。
2. 智能匹配：输出多维评分、差距项、建议动作。
3. 决策协同：形成推荐名单、面试清单、报告结论。
4. 行动复评：执行建议后复评，沉淀改进数据。

### 3）MVP能力边界
- 必备：账号权限、双画像、匹配分析、报告输出。
- 后续增强：面试模拟、流程自动化编排、行业模板市场。

### 4）关键激活与转化节点
- 节点A：首次成功生成岗位画像（产品激活）
- 节点B：首次完成有效匹配报告（价值感知）
- 节点C：连续复评带来指标改善（续费与扩容依据）

### 5）本节后续可展开讲解
- 每个功能模块的输入/处理/输出
- 用户角色差异化页面与权限逻辑
- 功能优先级与版本规划（MVP→增强版）

## 特色综述

### 1）产品特色
- 标准化输入：统一岗位与人才评价口径，降低主观偏差。
- 智能化决策：不仅“给分”，还能“给路径”。
- 闭环化运营：筛选、推荐、评估、复评完整打通。

### 2）经营特色
- 可量化价值：效率提升、错配率下降、转化率提升。
- 可持续优化：通过复评与数据沉淀持续提升模型效果。
- 可规模复制：适配院校、企业、人力服务机构多场景。

### 3）竞争壁垒
- 统一对象模型（岗位画像/人才画像）
- 统一决策核心（匹配引擎）
- 统一经营指标（激活率、报告率、匹配转化率、续费率）

### 4）本节后续可展开讲解
- 与竞品在流程、效果、成本的对比矩阵
- 各特色对应的可验证指标与验收口径
- 平台可复制能力的组织保障（交付标准化）

## 开发工具与技术

### 1）技术栈概览
- 后端：Go + go-zero（API编排、业务逻辑、中间件）
- 前端：TypeScript + Vite（交互与可视化）
- 智能扩展：Python（解析/模型）、Rust（高性能扩展）
- 数据层：MySQL + Redis

### 2）架构原则
- 先进性：支持 AI 能力演进与模块化扩展
- 稳定性：支持限流、熔断、灰度、回滚
- 扩展性：服务边界清晰，支持SaaS/私有化交付
- 安全性：鉴权、分层、审计、敏感信息保护

### 3）系统能力映射（现有→商业化）
- 认证权限 → 多租户机构隔离
- 岗位/人才管理 → 行业模板化配置
- 匹配与报告 → 标准版/专业版产品包
- 服务编排 → 私有化部署与API增值服务

### 4）技术里程碑（12个月）
- M1：统一数据字典与指标体系
- M2：匹配引擎参数化与可配置化
- M3：多租户与计费能力上线
- M4：岗位模板市场上线

### 5）本节后续可展开讲解
- 系统分层架构图与服务调用关系
- 核心接口清单与数据流转说明
- 技术选型理由与替代方案对比

## 应用环境

### 1）业务应用环境
- 院校就业指导场景
- 企业校园招聘/社会招聘场景
- 区域校企合作联合服务场景

### 2）部署应用环境
