#### 1.1 完整度计算算法
**位置**：`internal/logic/studentlogic.go`

**算法描述**：基于7个维度计算学生资料的完整度百分比
- 维度：姓名、学历、专业、技能、证书、实习、项目
- 每个维度权重相等（1/7）
- 返回值：0-100 的分数

#### 1.2 竞争力计算算法
**位置**：`internal/logic/studentlogic.go`

**算法描述**：基于数量指标评估学生的竞争力
- 基础分：50分
- 技能数量 > 5：+10分

#### 1.3 智能合并算法
**位置**：`internal/logic/studentlogic.go`

**算法描述**：在简历更新时智能合并新旧数据

**技能合并算法**：
- 使用哈希表存储技能名称和等级
- 合并时保留更高的掌握程度
- 如果等级相同，保留更长的年限

**证书合并算法**：
- 使用"名称+等级"作为唯一标识
- 去重处理，避免重复记录

**实习合并算法**：
- 基于"公司名称+职位"去重
- 如果描述更长，使用更详细的描述

**项目合并算法**：
- 基于项目名称去重
- 合并技术栈（去重）
- 保留更详细的项目描述


### 2. 职位匹配算法

#### 2.1 技能匹配度计算算法
**位置**：`internal/logic/matchlogic.go`

**算法描述**：计算学生技能与职位技能要求的匹配度
- 必需技能权重：1.5
- 普通技能权重：1.0
- 匹配比率 = 学生等级 / 职位要求等级（上限1.0）
- 最终得分 = (权重匹配总和 / 总权重) × 100


#### 2.2 证书匹配度计算算法
**算法描述**：计算学生证书与职位证书要求的匹配度
- 简单的名称匹配算法
- 匹配得分 = (匹配证书数 / 要求证书数) × 100

```go
func calculateCertsMatch(studentCerts []types.StudentCert, jobCerts []string) float64 {
    if len(jobCerts) == 0 {
        return 100.0
    }

    if len(studentCerts) == 0 {
        return 0.0
    }

    matchedCount := 0
    for _, jobCert := range jobCerts {
        for _, studentCert := range studentCerts {
            if studentCert.Name == jobCert {
                matchedCount++
                break
            }
        }
    }

    return float64(matchedCount) / float64(len(jobCerts)) * 100
}
```

#### 2.3 软技能匹配度计算算法
**算法描述**：基于5个维度的软技能差异计算匹配度
- 维度：创新、学习、抗压、沟通、团队协作
- 计算每个维度的绝对差异
- 平均差异 = 总差异 / 5
- 匹配度 = (1 - 平均差异 / 最大差异) × 100
- 最大差异 = 5.0

```go
func calculateSoftSkillsMatch(studentSkills, jobSkills types.SoftSkills) float64 {
    innovationDiff := math.Abs(float64(studentSkills.Innovation - jobSkills.Innovation))
    learningDiff := math.Abs(float64(studentSkills.Learning - jobSkills.Learning))
    pressureDiff := math.Abs(float64(studentSkills.Pressure - jobSkills.Pressure))
    communicationDiff := math.Abs(float64(studentSkills.Communication - jobSkills.Communication))
    teamworkDiff := math.Abs(float64(studentSkills.Teamwork - jobSkills.Teamwork))

    totalDiff := innovationDiff + learningDiff + pressureDiff + communicationDiff + teamworkDiff
    avgDiff := totalDiff / 5.0

    maxDiff := 5.0
    matchScore := (1.0 - avgDiff/maxDiff) * 100

    if matchScore < 0 {
        matchScore = 0
    }

    return matchScore
}
```

- 证书匹配权重：15%
- 软技能匹配权重：25%
- 经验匹配权重：25%

#### 3.2 Top类型提取算法
**算法描述**：按得分排序，提取前三个类型
- 使用冒泡排序按得分降序排列
- 返回得分最高的前3个类型

```go
func getTopTypes(scores map[string]int) []types.HollandTypeInfo {
    typeScores := make([]struct {
        typeChar string
        score    int
    }, 0, len(scores))

    for t, score := range scores {
        typeScores = append(typeScores, struct {
            typeChar string
            score    int
        }{t, score})
    }

    // 按得分降序排序
    sort.Slice(typeScores, func(i, j int) bool {
        return typeScores[i].score > typeScores[j].score
    })

    // 取前三个
    topTypes := make([]types.HollandTypeInfo, 0, 3)
    for i := 0; i < len(typeScores) && i < 3; i++ {
        topTypes = append(topTypes, types.HollandTypeInfo{
            Type:  typeScores[i].typeChar,
            Score: typeScores[i].score,
        })
    }

    return topTypes
}
```

```go
func getSuitableJobs(careerCode string, careerTypes map[string]types.HollandCareerType) []string {
    jobs := make(map[string]bool)

    // 为前三个类型收集职业
    for _, char := range careerCode {
        if careerType, ok := careerTypes[string(char)]; ok {
            for _, job := range careerType.SuitableJobs {
                jobs[job] = true
            }
        }
    }

    // 转换为切片
    result := make([]string, 0, len(jobs))
    for job := range jobs {
        result = append(result, job)
    }

    return result
}
```

#### 4.1 职位相似度计算算法
**算法描述**：计算两个职位之间的相似度
- 基于技能重合度计算
- 相似度 = (共同技能数 / 总技能数) × 100

```go
func calculateJobSimilarity(skills1, skills2 []types.Skill) float64 {
    if len(skills1) == 0 && len(skills2) == 0 {
        return 100.0
    }

    skillMap1 := make(map[string]int)
    for _, skill := range skills1 {
        skillMap1[skill.Name] = skill.Level
    }

    skillMap2 := make(map[string]int)
    for _, skill := range skills2 {
        skillMap2[skill.Name] = skill.Level
    }

    commonSkills := 0
    allSkills := make(map[string]bool)

    for name := range skillMap1 {
        allSkills[name] = true
    }
    for name := range skillMap2 {
        allSkills[name] = true
    }

    for name := range allSkills {
        if _, exists := skillMap1[name]; exists {
            if _, exists := skillMap2[name]; exists {
                commonSkills++
            }
        }
    }

    if len(allSkills) == 0 {
        return 100.0
    }

    return float64(commonSkills) / float64(len(allSkills)) * 100
}
```

#### 4.2 软技能相似度计算算法
**算法描述**：计算两个职位软技能的相似度
- 基于5个维度的差异
- 算法与学生-职位软技能匹配相同

```go
func calculateSoftSkillSimilarity(skills1, skills2 types.SoftSkills) float64 {
    diff := math.Abs(float64(skills1.Innovation-skills2.Innovation)) +
        math.Abs(float64(skills1.Learning-skills2.Learning)) +
        math.Abs(float64(skills1.Pressure-skills2.Pressure)) +
        math.Abs(float64(skills1.Communication-skills2.Communication)) +
        math.Abs(float64(skills1.Teamwork-skills2.Teamwork))

    avgDiff := diff / 5.0
    maxDiff := 5.0

    similarity := (1.0 - avgDiff/maxDiff) * 100
    if similarity < 0 {
        similarity = 0
    }

    return similarity
}
```
