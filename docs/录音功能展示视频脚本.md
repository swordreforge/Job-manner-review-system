# CareerPlanner 录音功能展示视频脚本

**版本**: v1.0
**日期**: 2026-04-20
**目标受众**: 投资/商业展示
**时长**: 3-5 分钟
**风格**: 录屏 + 旁白

---

## 定位声明

CareerPlanner 不是一个单点工具，而是一站式 AI 职业规划助手——从认识自我到拿到 offer，全链路覆盖，周期化长期追踪用户动态，陪伴学生成长的每一步。语音录音是其中最具交互性的功能之一，它让面试模拟从"打字问答"变成了"开口说话"，是整个系统闭环中的关键一环。

---

## 第一幕：痛点引入（0:00 - 0:40）

**画面**: 文字动画 + 数据可视化

> **旁白**: 每年超过 900 万大学生毕业生涌入就业市场。但职业规划不是一次考试——它是一个持续数月、甚至数年的成长过程。从认识自我到技能提升，从岗位匹配到面试突破，学生需要的不只是一个工具，而是一个**长期陪伴的系统**。

**画面**: 递增数据 → 学生焦虑剪影 → 传统服务碎片化示意（测评网站 / 招聘平台 / AI 聊天各管一段）

> **旁白**: 现有方案各管一段——测评完没后续，简历投完没反馈，AI 聊完没追踪。学生需要的是一站式闭环。

## 第二幕：产品亮相 — 一站式体系（0:40 - 1:30）

**画面**: CareerPlanner Logo → 首页快照 → 七大核心能力流程图浮现

> **旁白**: CareerPlanner，AI 驱动的一站式职业规划系统。从霍兰德职业测评到简历解析，从岗位画像到智能匹配，从职业图谱到规划报告，再到 AI 模拟面试——我们覆盖了学生职业发展的完整链路。

**画面**: 动画展示用户旅程——兴趣测评 → 简历上传 → 画像构建 → 岗位匹配 → 图谱探索 → 报告生成 → 面试训练

> **旁白**: 这不是清单式功能堆叠。每一个模块的数据都流转到下一个模块，形成闭环——你的测评结果影响匹配权重，你的简历解析驱动画像更新，你的面试表现反过来优化建议策略。

**画面**: 时间轴动画——大一入学测评 → 大二技能提升 → 大三岗位匹配 → 大四面试冲刺

> **旁白**: 更重要的是，CareerPlanner 不是一次性工具。我们通过周期化追踪，记录学生的每一步成长——技能变化、证书新增、实习经历补充——系统动态调整匹配和建议，实现真正的长期陪伴。

## 第三幕：聚焦录音 — 让面试真正"说话"（1:30 - 2:20）

**画面**: 快速剪辑进入「模拟面试」模块

> **旁白**: 在所有功能中，有一个模块最能体现我们的理念——面试不只是文字游戏，它是一场真实的对话。所以，我们让学生**开口说**。

**画面**: 录屏——进入面试页面，展示面试题目（如"请简述你最有挑战的项目经历"）

> **旁白**: 用户按下录音按钮，用自己的声音回答。就像真实面试一样——紧张、停顿、重述——全部保留。这种自然的交互方式，才是面试训练的本质。

**画面**: 录屏——点击「开始录音」，录音指示灯亮起，波形动画，倒计时显示

> **旁白**: 浏览器端通过 MediaRecorder API 实时采集麦克风音频，配合 Web Audio API 将音频重采样为 16kHz、16-bit、单声道 PCM——这是语音识别的工业标准格式，确保最高识别精度。

---

## 第四幕：技术内核 — 从声音到理解（2:20 - 3:10）

**画面**: 架构流程图动画

```
浏览器 MediaRecorder → Web Audio API(PCM转码) → Rust 语音网关(Axum)
    → FFmpeg 格式校准 → 讯飞星火 ASR(WebSocket 流式) → 文字返回前端
```

> **旁白**: 这套管线的设计哲学是"端侧预处理、服务端专注中继"。浏览器完成格式转换的脏活累活，Rust 网关只做协议对接和流式推送，讯飞星火引擎专注于识别本身——每一层各司其职，延迟控制在秒级。

**画面**: 性能卡片浮现——

| 指标 | 数据 |
|------|------|
| 识别延迟 | 秒级首字返回 |
| 音频时长限制 | 60 秒 |
| 网关内存占用 | 极低（Rust 单二进制） |
| 并发模型 | 流式帧推送（1280 字节/帧，40ms 间隔） |

> **旁白**: Rust 实现的语音网关内存占用极低，单二进制部署，天然适合高并发场景。同时，我们采用流式分帧推送技术，音频边采边传，用户感知到的延迟几乎为零。

---

## 第五幕：闭环价值 — 录音只是起点（3:10 - 4:00）

**画面**: 录屏——用户录音转文字后，AI 实时给出面试评估

> **旁白**: 录音识别不是目的，闭环才是。声音化为文字后，DeepSeek 大模型从内容完整度、逻辑结构、表达力三个维度进行专业评估，给出具体可执行的改进建议。

**画面**: 展示 AI 评估结果界面（评分、建议、对比）

> **旁白**: 更关键的是——这一切数据回流到系统中。面试表现影响职业规划的优先级建议，技能短板触发学习路径推荐，匹配差距推动简历优化方向。这不是孤立的录音功能，而是一站式体系中有机的一环。

**画面**: 快速展示用户成长时间线——测评记录、简历更新、面试成绩、报告迭代

> **旁白**: 周期化追踪让每一次练习都有迹可循。学生可以看到自己的面试表现随时间变化，系统根据历史数据动态调整面试难度和侧重点。这才是职业规划系统应有的样子——不是给你一个答案，而是陪你走到终点。

## 第六幕：技术壁垒与商业延展（4:00 - 4:30）

**画面**: 四服务架构图浮现——Go 主服务 / Rust 语音网关 / Rust 教师服务 / React 前端

> **旁白**: 从商业视角看，CareerPlanner 的技术壁垒来自三个层面：

- **一站式闭环**: 数据在模块间自由流动，单项工具无法复制这种系统性价值
- **Rust 双引擎**: 语音网关与教师服务均采用 Rust 实现，极致性能，单二进制部署，运维成本极低
- **语音交互基础设施**: 这条管线未来可扩展至语音简历、企业面试训练、语音测评等场景，是一个可复用的技术资产

```
痛点（碎片化） → 一站式体系（CareerPlanner 全景） → 聚焦录音（交互性功能）
```
