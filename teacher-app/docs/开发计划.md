# 教师端API开发计划

## 项目概述

教师端API基于Rust + Actix-web框架开发，主要提供数据管理和简单运维功能，服务于高中职业规划系统的教师用户。

## 技术栈

- **语言**: Rust 2024 Edition
- **Web框架**: Actix-web 4.9
- **数据库**: MySQL (使用sqlx)
- **异步运行时**: Tokio
- **序列化**: Serde
- **验证**: Validator
- **日志**: env_logger
- **错误处理**: anyhow

## 接口设计规范

### RESTful API规范
- 使用标准HTTP方法（GET、POST、PUT、DELETE）
- 使用JSON格式数据交换
- 统一响应格式
- 合理的HTTP状态码使用

### 统一响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 错误响应格式
```json
{
  "code": 400,
  "message": "错误信息",
  "error": "详细错误描述"
}
```

## 数据库设计

### 主要数据表
- `teachers` - 教师信息表
- `students` - 学生信息表（关联现有表）
- `test_records` - 测试记录表（关联现有表）
- `career_reports` - 职业规划报告表（关联现有表）
- `system_logs` - 系统日志表
- `backup_records` - 备份记录表

## 安全考虑

1. **认证授权**: JWT Token认证
2. **数据验证**: 请求参数严格验证
3. **SQL注入防护**: 使用参数化查询
4. **CORS配置**: 严格的跨域控制
5. **敏感信息**: 加密存储
6. **访问日志**: 记录所有API访问

## 性能优化

1. 数据库连接池
2. 查询结果缓存
3. 分页查询
4. 异步处理
5. 索引优化
